# R2 Source Update — 2026-10-17

**Status:** source-only update to `2.0.0-beta.1`. The version is unchanged. R2 has no GitHub Release or public binary download. The current local candidate identity and checks are recorded in [Acceptance](ACCEPTANCE.md).

## What changed

The expanded detail header now presents recognized current-plan identifiers with clearer display names:

| Returned identifier | Display label |
| --- | --- |
| `prolite` | `PRO LITE` |
| `plus` | `PLUS` |
| `pro` | `PRO (MORE)` |
| `promax` | `PRO (MAX)` |

Matching is case-insensitive. Other non-empty values remain readable; null or blank values use the localized Unknown fallback. The backend/model value is not rewritten, and the compact 96-DIP widget is unchanged. The 14px bold badge uses mint for Plus, violet for the Pro family, and neutral styling for unknown values. Plan names do not determine quota windows, eligibility, price, or billing. The pinned [Codex auth source](https://github.com/openai/codex/blob/ce0323f2f2d3b25e82806cd555237da3db4e1897/codex-rs/protocol/src/auth.rs#L130-L145) renders `KnownPlan::ProLite` with the generic name `Pro`; R2 deliberately uses `PRO LITE` for raw `prolite` to distinguish it from raw `pro`, shown as `PRO (MORE)`. These all-caps labels are R2 UI wording, not upstream display spelling or billing terms.

## R1 and R2: verified scope, different delivery lines

| Area | WPF R1 | Tauri R2 |
| --- | --- | --- |
| Project status | `v1.1.3` is the documented published Latest Release. | Separate `2.0.0-beta.1` source preview; no R2 Release or public download. |
| Implementation and delivery | Native WPF Windows x64, self-contained published EXE. | Separate Tauri 2 / Rust / React + TypeScript app; local candidate is unpackaged and requires WebView2. |
| Window and preferences | Full and Orb views; documented R1 settings are language and refresh interval. | 96×96-DIP compact widget, 340×480-DIP detail view, and 340×360-DIP Settings surface. Settings expose theme, language, and 60 / 120 / 300-second refresh intervals. |
| Quota and reset data | R1 behavior remains governed by its own source and acceptance record. | Displays returned quota windows and reset-credit fields; it does not infer a window from the plan label. Refresh feedback distinguishes complete and incomplete quota outcomes. |
| Local activity | No R1 activity comparison is asserted here. | Reads local session token-count records for a local-day chart; this is token activity, not quota consumed. Missing data is left unknown and partial totals are lower bounds. |

R2 is not a replacement for R1, and this update does not claim full Plus/Pro parity or coverage of every account/provider state.

## What R2 does today

- Reads the current quota and reset-credit data implemented by the R2 source. Window labels and durations use the returned window durations rather than being guessed from the plan name.
- Provides English and Simplified Chinese, plus System / Light / Dark themes. System follows the Windows app-color setting; it does not track wallpaper, time of day, or a Codex account setting.
- Provides tray Open, Refresh, and Exit actions. The app window is configured not to add a taskbar button.
- Provides a local activity view with twelve local-time buckets for the day. Unknown bucket positions remain blank. Compact counts currently use `K` and `M` suffixes; the formatter does not switch to a `B` suffix.
- Displays reset-credit counts and expiry only when valid returned fields are available; unavailable or partial fields are not fabricated.

The source does not implement Follow Codex, low-quota alerts, or an About page. R2 does not integrate the Codex app-server and does not provide real-time approval/session control, predictions, reminders, or ordinary ChatGPT/API usage monitoring.

## Independent operation and window lifecycle

R2 does not launch or monitor the Codex Desktop process and has no rule to exit when Codex closes. Closing the R2 window hides it; the tray Exit action quits R2. The quota reader obtains local authentication data and makes authenticated HTTP requests directly. **Source-level implication:** that request path does not require Codex Desktop to be running when the local authentication data and network are usable. Missing or unusable authentication, unauthorized responses, rate limits, and request failures are represented as quota states such as Signed out, Unavailable, Rate limited, or Stale—not as “Codex is not open.”

Hover expansion, leave-to-compact, Settings remaining open during editing, and tray Open restoring the compact view are implemented flows. The current plan-label candidate was human-reported as working, but the public evidence does not include a detailed trace for each lifecycle, no-Codex, or failure state. Do not read these source contracts as broad native-runtime acceptance.

## Requirements and distribution

Running an R2 candidate requires Windows x64, the Microsoft Edge WebView2 Runtime, usable local Codex authentication data, and network access for quota requests. End users do not need to install .NET, Node.js, Rust, or Visual Studio Build Tools. R2 is not self-contained: it does not bundle or install WebView2. No installer, updater, or code-signing claim is made, and clean-machine portability has not been verified. See [Development](DEVELOPMENT.md) for maintainer build prerequisites.

The current local candidate is 20,928,512 bytes with SHA-256 `5BF6AAFB87791556F543863FF7D8691CA363CFB2727A4351DB00A9C2FF36099A`. The user reported that this candidate worked without issue. That report is limited: it does not establish broad DPI coverage, provider/account switching, clean-machine behavior, shell icon appearance, or every interaction path. This hash is not a GitHub Release checksum because the candidate is not published as a download. The earlier beta.1 executable has a different hash; see [Acceptance](ACCEPTANCE.md) to distinguish them.

## Privacy and data boundaries

- R2 reads local Codex authentication data from `CODEX_HOME` or the default `.codex` directory to make authenticated GET requests to `https://chatgpt.com/backend-api/wham/usage` and `https://chatgpt.com/backend-api/wham/rate-limit-reset-credits`.
- R2 also scans a bounded portion of local `sessions/*.jsonl` files for token-count records. These are conversation-bearing session files, so it is not accurate to promise that the application never reads or inspects bytes from conversation-bearing data. Extracted token-count fields are used for the chart; session-file contents are not sent to a product server.
- The scanner limits discovery to 64 candidate files, 8 MiB total, 1 MiB per file, and 256 KiB per line, with a two-second cooperative deadline checked between operations. Synchronous filesystem calls can exceed that elapsed-time target. See the [R2 source data-boundary details](../../../SECURITY.md#r2-beta-source-data-boundary).
- The current source defines no product telemetry or analytics endpoint. This describes this source version, not future versions.
- Quota, reset-credit, and activity views are distinct. Token counts are not quota percentages; partial activity totals are lower bounds. Do not infer billing, price, reset availability, or missing values.

Do not publish authentication files, tokens, raw responses, session files, account screenshots, or private diagnostics. The privacy boundaries above describe source behavior; they are not a security audit or a promise about future versions.

## Verification and remaining limits

For this local source candidate, the frontend suite passed 53 tests, Rust unit tests passed 20, the frontend build passed, and the locked offline x64 MSVC custom-protocol build succeeded. The Rust build emitted two compiler warnings. The user reported the candidate worked; no broader interaction trace is claimed here. See [Acceptance](ACCEPTANCE.md) for the distinct historical first-candidate record and current candidate identity.

Still not verified: broad Windows DPI and monitor/work-area coverage; provider/account-switch transitions; full Plus/Pro feature parity; clean-machine behavior when WebView2 is missing; native WebView focus/event ordering; shell/tray/shortcut icon appearance; installer, updater, or signed distribution. Component tests and a successful build do not establish these behaviors.

## R2 当前功能

- 读取 R2 源码实现的当前额度和 reset-credit 数据。区间标签和时长使用接口返回的实际区间时长，而不是根据套餐名称猜测。
- 支持 English / 简体中文，以及 System / Light / Dark 主题。System 跟随 Windows“应用模式/应用颜色”设置；不会跟随壁纸、时间或 Codex 账户设置。
- 提供托盘 Open、Refresh、Exit；应用窗口配置为不在任务栏单独显示按钮。
- 提供本地活动视图，以本地时间显示一天内的 12 个区间。未知区间留空。当前紧凑计数格式使用 `K` 与 `M` 后缀，不会切换为 `B` 后缀。
- 仅在返回字段有效时显示 reset-credit 数量和到期时间；不会伪造不可用或部分数据。

源码未实现 Follow Codex、低额度提醒或 About 页面。R2 不集成 Codex app-server，不提供实时审批/会话控制、预测、提醒，也不监控 ChatGPT 普通聊天或 API 用量。

## 独立运行与窗口生命周期

R2 不会启动或监控 Codex Desktop 进程，也没有在 Codex 关闭时退出的规则。关闭 R2 窗口会将其隐藏；托盘 Exit 操作用于退出 R2。额度读取器直接获取本地身份验证数据并发送带身份验证的 HTTP 请求。**源码层面的推论：**只要本地身份验证数据和网络可用，该请求路径就不需要 Codex Desktop 正在运行。身份验证缺失或不可用、未授权响应、请求受限和请求失败会表示为“需要登录”“不可用”“请求受限”或“数据过期”等额度状态，而不是“Codex 未打开”。

悬停展开、移开后回到紧凑视图、编辑时 Settings 保持打开、托盘 Open 恢复紧凑视图均已在源码中实现。当前套餐标签候选版有人反馈试用正常，但公开证据没有为每个生命周期、无 Codex 或失败状态提供详细交互记录。不要把这些源码契约误读为广泛原生运行验收。

## 运行要求与分发

运行 R2 候选版需要 Windows x64、Microsoft Edge WebView2 Runtime、可用的本地 Codex 身份验证数据，以及额度请求所需的网络。终端用户不需要另行安装 .NET、Node.js、Rust 或 Visual Studio Build Tools。R2 不是自包含程序，不会捆绑或安装 WebView2。没有安装程序、自动更新器或代码签名声明；全新设备上的可移植性尚未验证。维护者构建前置条件见 [Development](DEVELOPMENT.md)。

当前本地候选版大小为 20,928,512 字节，SHA-256 为 `5BF6AAFB87791556F543863FF7D8691CA363CFB2727A4351DB00A9C2FF36099A`。用户反馈该候选版试用正常。此反馈范围有限，不代表已验证广泛 DPI、服务商/账户切换、全新设备行为、Windows Shell 图标外观或所有交互路径。由于候选版没有作为下载发布，该哈希不是 GitHub Release 校验值。此前的 beta.1 可执行文件使用不同哈希；请在 [Acceptance](ACCEPTANCE.md) 中区分。

## 隐私与数据边界

- R2 从 `CODEX_HOME` 或默认 `.codex` 目录读取本地 Codex 身份验证数据，并向 `https://chatgpt.com/backend-api/wham/usage` 和 `https://chatgpt.com/backend-api/wham/rate-limit-reset-credits` 发送带身份验证的 GET 请求。
- R2 也会扫描部分本地 `sessions/*.jsonl` 文件以查找 token-count 记录。这些文件包含对话内容，因此不能准确承诺应用从不读取或检查含对话数据的字节。图表使用提取的 token-count 字段；session 文件内容不会发送到产品服务器。
- 扫描器限制为最多 64 个候选文件、总计 8 MiB、单文件 1 MiB、单行 256 KiB，并在操作间协作式检查两秒期限。同步文件系统调用可能超过该时长目标。详见 [R2 源码数据边界](../../../SECURITY.md#r2-beta-source-data-boundary)。
- 当前源码未定义产品 telemetry 或 analytics endpoint。这只描述当前源码版本，不构成对未来版本的承诺。
- 额度、reset-credit 与活动视图彼此独立。Token 数量不是额度百分比；部分活动总量是下限。不要推断计费、价格、重置机会或缺失数值。

不要公开身份验证文件、token、原始响应、session 文件、账户截图或私人诊断信息。以上隐私边界描述当前源码行为，不是安全审计，也不构成对未来版本的承诺。
