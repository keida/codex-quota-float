# Historical Scale Contract

Status: **superseded; historical reference only**.

The former Product Scale contract (including `40%`, `70%`, and `100%` selectors, scale-specific layouts, and scale-specific settings claims) is not the active WPF R1 contract. Product Scale was removed from the simplified R1 surface. Use [`SIMPLIFICATION-CONTRACT.md`](SIMPLIFICATION-CONTRACT.md) for the current contract.

Windows DPI remains a separate runtime concern. The accepted baseline is Windows 100% / 96 DPI; native 125% and 150% DPI runtime acceptance remains `NOT VERIFIED / OUT OF R1 ACCEPTANCE SCOPE`.
